## 4．課題A：XOR・全加算器・RCA

WordのA-1～A-4へ記入します．`Signal`はbool，`Word`は32本のSignalを持ち，bit 0がLSBです．

1. `examples/gates_and_wires.c`と`make examples`で配布ゲート・配線・MUXを確認します．XORは学生が基本ゲートを接続して実装します．
2. XORの全4入力，FAの全8入力について，期待値を先に考え，自分の関数の実出力と比較します．FAはSumとCoutの両方を記録します．
3. FAの接続図または論理式を描き，内部Signal・関数呼出し・出力生成順・自分のコード位置を対応させます．完成コード全文の貼付は必須ではありません．
4. RCAはFAを32段接続します．4ビット等に縮めた説明図で，具体的なA・B・Cin・Sum・CoutとC0から上位への伝播を追います．4ビット図は説明用で，32ビット実装の代わりにはなりません．
5. `make test-a`と`make example-adder`を実行します．後者は`examples/observe_adder.c`が自分の関数を呼びます．スライドp.25の6例を含め，境界例・Cin・carry_outを確認し，符号付きoverflowとの違いを説明します．

## 5．課題B：1ビットALU・32ビットALU・SUB

WordのB-1～B-3へ記入します．alu1のAND・OR・FA・結果選択MUX，Binvertとb／NOT(b)選択，Cin／Coutを示します．alu32は共通opでalu1を32段接続し，キャリーを次段へ渡します．各図を自分の関数・補助Signal・呼出し・制御値と対応させます．

| 演算 | op[2:0] | Cの配列順 `{op[0], op[1], op[2]}` |
|---|---|---|
| AND | 000 | `{0,0,0}` |
| OR | 001 | `{1,0,0}` |
| ADD | 010 | `{0,1,0}` |
| SUB | 110 | `{0,1,1}` |

SUBではalu1内でBを条件反転し，alu32のC0をBinvert（op[2]）に接続します．Bを二重に反転していないか，opの添字を取り違えていないか確認します．alu1のcoutはFAの出力です．alu32の最終キャリーC32は内部信号です．RCAの独立したcarry_in／carry_outとは区別してください．

自分で選んだSUBの1例について，BまたはNOT(B)，C0，後続Cin，32ビットの結果を具体値で説明します．A>B，A=B，A<Bのうち少なくとも複数を試し，4演算を複数入力で確認します．`make test-b`，`make example-alu`を実行します．観察用の`examples/observe_alu.c`も自分の関数を呼びます．Bの下位依存はXOR／FAです．RCAだけの不合格でBの確認を省略しないでください．

## 6．図・論理式とコードの対応

図には入力・出力・内部信号・部品名・制御・接続方向を書きます．本文から図番号を参照し，自分の変数名，関数名，コード位置または短い抜粋と対応させます．前段の出力を計算してから後段へ渡す呼出し順も説明してください．図だけ，コードだけ，ログだけで説明を終えず，その接続で得た実結果へ結び付けます．

指定部品を接続する課題です．整数へ変換して直接加減算・ビット演算する方法，Cの`^`や`!=`によるXOR，分岐によるMUX代用，答え一覧・期待値関数の呼出しは実装条件を満たしません．ループ・添字・等価な接続補助は使えます．有効な別解では接続が等価である理由を示します．詳しいAPI・構成条件は[README](../README.md#interfaces)を参照してください．

## 7．期待値・実値・合否・選定理由

各表にID，入力A・B，Cinまたは制御，期待値，実値，合否，選定理由を記入します．期待値は比較の基準，自分の回路が返した値が実値です．未完成時に表示された期待値を実測値として転記しないでください．不一致は隠さず，最初に異なる信号と原因を説明します．中間信号も自分の関数・変数から観察します．

| 公式グループ | 全合格時の比較数 |
|---|---:|
| 配布部品 | 362 |
| XOR（4入力） | 8 |
| FA（8入力） | 16 |
| RCA | 536 |
| alu1 | 64 |
| alu32 | 1640 |
| 全公式グループ | 2626 |
| `test-a` | 922 |
| `test-b` | 2090 |

比較数は入力数ではありません．同じ入力をfalse／trueの出力初期値で再度与えます．RCAは268入力組，alu32は820入力組であり，32ビット全入力を網羅しません．固定入力は`x=(1664525*x+1013904223) mod 2^32`で生成し，RCA seedは`0x202605a1`，ALU32 seedは`0x202605b2`です．各128組のA/Bを生成し，ALU32は4制御で確認します．RCAのCinはケース番号の偶奇で交互です．

独自テストの初期例はRCA2入力（4比較）とALU32の1入力組（2比較）です．これだけでレポート完成とはなりません．追加ケースのIDと選定理由を示してください．最後に`make test`と`make test-student`を実行し，末尾のRESULT／SUMMARYと終了値を記録します．省略されたグループを合格件数へ数えません．Makeの終了2とrunnerの終了値は別なので，最初の診断も記録します．

## 9．ZIP作成

ZIPを展開した直下が次の構成になるように，3ファイルだけを格納します．

```text
tasks/
  adder_task.c
  alu_task.c
tests/
  student_cases.c
```

最上位に`compsys-ex05/`などの親フォルダーを付けません．`include/`，`src/`，`examples/`，`tools/`，公式テスト，Makefile，`build/`，`.git/`，ログ，実行ファイル，Word，PowerPoint，完成解答資料を含めません．

macOS／GNU/Linuxではリポジトリ直下から，例えば次で作成できます．既存の同名ZIPを再利用せず，出力先の古いZIPを退避してから作成してください．

```sh
zip 学籍番号_ex05_code.zip tasks/adder_task.c tasks/alu_task.c tests/student_cases.c
unzip -l 学籍番号_ex05_code.zip
```

Windowsでは空の提出用フォルダーに上記`tasks/`と`tests/`を作り，指定3ファイルだけをコピーして，この2フォルダーを選択してZIPへ圧縮します．どの方法でも，別の空フォルダーへ展開し，階層と3ファイルの内容を確認してください．
